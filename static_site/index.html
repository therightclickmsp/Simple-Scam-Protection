What it does

Built around how tech-support scams actually work.

Almost every scam call ends the same way: "install this app so I can fix your computer." Simple Scam Protection breaks that step.

Remote-access blocker

Finds AnyDesk, TeamViewer, UltraViewer, RustDesk, ScreenConnect and more. Closes them the instant they start and helps you remove them. Microsoft Quick Assist is trusted by default - you can block it in Settings.

Fake pop-up closer

Spots fake 'Your PC is locked - call Microsoft' pages in Chrome, Edge, Firefox, Brave and Opera, and closes them automatically.

Settings password

A family member sets a password. Without it, nobody can switch protection off, trust a tool, clear the log, quit or uninstall.

Scammer-trick warnings

Event Viewer, netstat, tree, syskey, msconfig - the tools scammers open to fake 'infections'. You'll get a clear warning.

Link & message checker

Spots misspelled brand names, look-alike letters, odd domain endings, raw IP addresses and scam phrases.

Scam website blocking

Blocks a built-in list of fake support and refund sites on your whole PC. Asks Windows for permission once.

Trusted list, scam-proofed

Use remote tools for work? Mark them trusted - but only after typing a confirmation, so a caller can't rush you.

Private activity log

A simple history of everything blocked or flagged. Stored only on your PC. No accounts, no tracking.

Create a password hash (run once on any PC)

SimpleScamProtection.exe --hash-password

Installer options (MSI: same names without the slash, e.g. NOAUTOSTART=1)

  • /ALLOW=screenconnect,teamviewer

    Pre-trust your own remote tools so your RMM / remote agent is never blocked

  • /PASSWORDHASH=pbkdf2_sha256$…

    Lock settings & uninstall with a password (hash only - no plain password in scripts)

  • /NOAUTOSTART

    Don't start for every user at logon

  • /NOSITEBLOCK

    Don't add the scam-site block to the hosts file

  • /NOPOPUPBLOCK

    Don't close fake virus pop-ups by default

  • /DIR="D:\Apps\Simple Scam Protection"

    Custom install folder (Setup.exe only)

Change policy later without reinstalling: SimpleScamProtection.exe --configure --allow …. Policy lives in C:\ProgramData\SimpleScamProtection (admin-only).

Questions

Good to know

The one rule that beats every scam: real companies never call you to fix your computer.

Is Simple Scam Protection really free?

Yes. No subscription, no account, no ads. Everything runs on your PC. If it helps you or your family, you can buy me a coffee.

Does it send my data anywhere?

No. The activity log and settings stay in your Windows user folder. The link checker in the app - and on this page - works fully offline.

Can I install it on my parents' PC?

That's exactly who it's for. Install it once and it starts with Windows, runs in the tray and needs no attention. Warnings are big and written in plain language.

What if I use TeamViewer or AnyDesk for work?

Open Settings & Trusted, select the tool and type the confirmation phrase. That tool will then be allowed. The typed step is there so a scammer can't casually talk someone through it.

Why is Microsoft Quick Assist allowed?

Quick Assist is built into Windows and is how many families and IT teams help each other, so it's trusted by default. Scammers use it too - if nobody you know uses it to help you, untrust it in Settings & Trusted and it will be blocked like the others.

Why does Windows show a warning when I run it?

The app isn't code-signed yet, so Windows SmartScreen doesn't recognise the publisher. Click More info, then Run anyway.

How does the fake pop-up closer work?

It watches browser window titles for the tell-tale signs of fake 'Microsoft security alert' pages - like 'Your PC is locked' together with 'call support' or a toll-free number. It first closes just that tab; if the page fights back it closes the browser.

What does the settings password protect?

Turning off any protection, trusting a remote tool, clearing the activity log, quitting the app and uninstalling it. After 5 wrong tries it locks for a minute. IT admins can set it during a silent install.

Can IT teams or MSPs deploy it with an RMM?

Yes. The installer supports /VERYSILENT with options to pre-trust your own remote tool (so your RMM agent isn't blocked), set a password hash, and skip auto-start or site blocking. Silent uninstall is supported too.

Is there an MSI for Intune or Group Policy?

Yes - SimpleScamProtection.msi (64-bit, per-machine). Use msiexec /i ... /qn with properties like ALLOW=screenconnect, NOAUTOSTART=1 or PASSWORDHASH=. Upgrades install over the old version automatically.

Is it an antivirus?

No. It targets the specific tricks tech-support scammers use. Keep Windows Defender (or your antivirus) turned on as well.

Can it catch every remote tool or scam link?

It recognises well-known tools by name and checks links with rules. Brand-new or renamed tools and brand-new scam sites may be missed - when in doubt, hang up and call a family member.
